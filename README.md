# スイング候補スキャナー

GitHub のクラウド上で自動実行され、東証 約3,700銘柄からスイングトレード候補を抽出して
Web ページ (GitHub Pages) に公開します。PC の電源は不要です。

| 時刻 (平日) | 内容 |
|---|---|
| 16:40 | 通常スキャン：全銘柄を分析して翌日の候補を作成 (約5分) |
| 9:20 / 12:45 | ザラ場チェック：候補だけを今の株価で再判定 (約1分) |

ザラ場チェックでは各候補に ◎買い条件OK / △上がりすぎ・弱い動き / ✕損切りライン到達 を表示し、
「今買うなら」の損切り・利確ラインも現在値から計算し直します。
※ GitHub の定時実行は混雑時に 5〜20分ほど遅れることがあります。株価は最大20分ほど遅れます。

**今すぐ更新したいとき**：GitHub の「Actions」→「swing-scan」→「Run workflow」→ mode で
`live` (候補の再チェック・約1分) か `full` (全銘柄・約5分) を選んで実行。
スマホでもブラウザから GitHub にログインすれば同じ操作ができます。

## 表示される情報
- 相場判定 (日経平均の75日線・200日線で 通常 / 注意 / 停止 の3段階。注意は株数を自動で減らし、停止は新規の買いなし) と主要指数 (日経平均・S&P500・NASDAQ・SOX・VIX・ドル円)
- 候補銘柄 (押し目買い=メイン / ブレイクアウト=参考)：最初の損切り、資金5万円での買い方 (100株 or 単元未満株の株数)
- 企業の背景：時価総額・PER・PBR・配当利回り・ROE・増収率・営業利益率、Wikipedia の会社概要、事業内容
- 推奨銘柄のポジション管理：保有中の推奨銘柄と「明日の逆指値」(トレーリングストップ)
- ルールの根拠：5年間・東証全銘柄での検証結果
- 各候補の「ライブチャート」(開いたときに TradingView のチャートを読み込み。表示されない場合はリンクから TradingView で開く)
- 決算予定日 (保有中にまたぐ場合は警告)、TDnet 適時開示、Google ニュース
- セクターの強弱、市況ニュース
- バックテスト (過去約1年半の成績) と フォワードテスト (実際の推奨の成績を毎日記録)

## 答え合わせページ (check.html)
ページ上部の「🔍 答え合わせ」から開けます。毎日の候補を各戦略の上位10位まで自動で記録し、
「翌朝の寄付きで買い、ルールどおりに売った」場合の成績を次の観点で集計します。
- **バックテストどおりか**：実際の平均R (損益÷最初の損切り幅) が、バックテストから計算した「想定範囲 (90%)」に入っているか。
  決済10件未満は判定保留。範囲の下に外れ続けたら要注意
- **累積Rのグラフ**：実際の成績と「バックテストの平均どおりだった場合」の線を比較
- **朝 (9:20)・昼 (12:45) のザラ場判定は効いているか**：◎ / △ / ✕ ごとの成績
- **順位で差があるか** (1〜3位 / 4〜6位 / 7〜10位)、**相場判定ごと** (通常 / 注意 / 停止)、**売った理由ごと**の成績

記録は `history/picks.json` に1件1行で保存されます。結論が見え始めるのは決済30件を超えたあたりからです。

## 仮想売買シミュレーター
ページ上部の「🧪 仮想売買シミュレーターを開く」、または各候補の「🧪仮想で買う」から使えます。
- 本物のお金を使わず、初期資金 (初期値5万円) で売買を練習
- 「翌営業日の寄付きで買う」(ルールどおり) か「指定した価格で買った」を選んで注文
- 毎営業日夕方の更新データで、損切りの引き上げ・損切り・最長30日での売却を**スキャナーと同じルールで自動処理**
- 手動で売ることも可能。評価額・確定損益・含み損益・勝率・売買履歴を表示
- 記録は**そのブラウザの中だけ**に保存されます (スマホとPCで別々)。「バックアップを書き出す/読み込む」で移せます
- 東証の全銘柄 (コード入力) で使えます。初回の通常スキャン (16:40 または full 実行) の後から利用可能

## 初回セットアップ (15分程度・無料)
1. https://github.com でアカウントを作成
2. 右上「+」→「New repository」→ 名前 `swing-scanner`、**Public** を選択して作成
   (無料で Pages を使うには Public が必要。公開されるのは株価分析結果のみで個人情報は含みません)
3. 作成直後の画面の「uploading an existing file」をクリックし、このフォルダの中身
   (`scan.py` `sim_template.html` `config.json` `requirements.txt` `universe.csv` `README.md` と **`.github` フォルダ**) をドラッグ＆ドロップ →「Commit changes」
   - `docs` `history` フォルダはアップロード不要です
4. リポジトリの「Settings」→ 左メニュー「Pages」→ Source を **GitHub Actions** に変更
5. 「Settings」→「Actions」→「General」→ 一番下 Workflow permissions を **Read and write permissions** にして Save
6. 「Actions」タブ → 左の「swing-scan」→「Run workflow」で初回実行 (5〜8分)
7. 完了後 `https://<GitHubユーザー名>.github.io/swing-scanner/` を開く (スマホのホーム画面に追加すると便利)

以降は平日夕方に自動更新されます。

## スマホ通知 (任意)
Discord のチャンネル設定 →「連携サービス」→「ウェブフック」で URL を作成し、
GitHub の「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で
名前 `DISCORD_WEBHOOK_URL`、値にその URL を登録すると、夕方は上位銘柄、
朝・昼は「◎買い条件OK」の銘柄が通知されます。

## 設定の変更 (`config.json`)
| 項目 | 意味 | 初期値 |
|---|---|---|
| budget | 運用資金 (円) | 50000 |
| risk_per_trade_pct | 1回の許容損失 (資金に対する%)・相場判定「通常」時 | 2.0 |
| max_positions | 同時に持つ銘柄数の上限・「通常」時 | 3 |
| caution_risk_pct | 相場判定「注意」時の許容損失 (%) | 1.0 |
| caution_max_positions | 相場判定「注意」時の保有上限 | 2 |
| min_turnover_yen | 最低売買代金 (20日平均) | 5000万円 |
| max_atr_pct | ATR が株価のこの%を超える荒い銘柄を除外 | 4.0 |
| stop_atr | 最初の損切り = 買値 − ATR × この値 | 2.0 |
| trail_atr | 損切りの引き上げ = 最高終値 − ATR × この値 | 3.0 |
| target_r | 利確指値 (損切り幅の何倍か)。null なら指値なしでトレーリング | null |
| max_hold_days | 最長保有日数 | 30 |
| history_picks_per_strategy | 「推奨」として成績を追う上位の銘柄数 (ポジション管理にも使用) | 3 |
| track_top_n | 答え合わせ用に記録する上位の銘柄数 (config.json に無ければ 10) | 10 |

GitHub 上で `config.json` を開き、鉛筆アイコンで編集・保存すれば次回から反映されます。
